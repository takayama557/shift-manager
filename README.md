# shift-manager
シフト管理システム

https://takayama557.github.io/shift-manager/


【使い方】
・カレンダー
    希望がある日のカレンダーのマスにタップすると希望（出勤・休み）が出せます。
    自動生成ボタンを押すと、希望がない箇所を設定に応じて自動で埋めてくれます。
    生成済みのマスをクリックすると手動修正できます。

・スタッフ管理画面
    スタッフ追加画面で、名前・レベル・最大連勤日数・出金できない曜日・アイコンカラーを設定できます。
    登録されているスタッフは、変更、削除することができます。

・生成条件画面
    基本の必要人数/日・必要レベルとそのレベルの必要人数・定休日を設定できます。

・自動生成履歴
    自動生成の履歴を表示します。

・ローカルストレージに保存されます
　　右上の「データを書き出す」でデータを保存できます。

【保存について】
データは同じブラウザ・同じ端末のローカルストレージに保存されます。別端末や別ブラウザとは共有されません。ブラウザのデータ削除で消える場合があるため、「データを書き出す」でバックアップしてください。
この版の自動生成は簡易です。生成結果を確認して手動調整してください。
